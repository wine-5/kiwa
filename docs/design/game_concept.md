# 際 -KIWA- 注ぎ勝負

## テーマの解釈

お題「かさ」を **嵩（かさ）** と読み替える。ひとつの器に注いだ液体の「嵩」を、
二人が交互に増やしていく。

## 一行で言うと

交互に注ぎ、こぼした方が負け。

## ルール

- 二人が交互に、**ひとつの器**へ茶を注ぐ
- 注ぐ量は「押している間だけ注がれる」。離すと止まる
- 1回の手番で**最低限は注がなければならない**（パスできない）
- 器があふれた瞬間、**注いでいた側の負け**
- **際（きわ）は器の口そのもの**。隠された数字ではなく、常に「縁いっぱい」が限界
- **器は毎局変わる**。入る量が器ごとに違うので、あと何回注げるかの見当は毎回つけ直しになる
- 対局の前に**花月の札**を引いて先攻後攻を決める
- **3本先取**で試合の勝ち

### 出てくる器

注ぐ速さは器によらず一定なので、容量がそのまま「口まで満たす時間」になる。

| 器 | 容量（湯呑を 1.0 として） | 感じ |
|---|---|---|
| ぐい呑 | 0.25 | 一手でも満ちる。事故が起きやすい |
| そば猪口 | 0.75 | 細く深いので、嵩の上がり方が速く見える |
| 湯呑 | 1.00 | 基準 |
| 茶碗 | 1.83 | なかなか満ちない。長い我慢になる |

寸法は `src/game/view/CupGeometry.h` の `shapeOf` と `tools/make_models.py` の
`make_vessel` が同じ式を共有している。**片方だけ直すと液面が内壁から浮く**ので必ず両方直す。

## 駆け引きの核

縁は見えているのに、**どこで止めるかは自分で決めなければならない**。
少なく注げば安全だが、こぼれるまでの余地を相手に残す。多く注げば相手を追い込めるが、
自分がこぼすリスクを負う。**際をどこまで攻めるか**の勝負。

器が毎局変わることで、前の局の勘がそのままでは使えない。

## 画面の流れ

1. **相手を選ぶ（タイトル）** — 二人で打つか、一人で打つか。一人なら二の手を任せる相手を選ぶ
2. **先攻後攻決め** — 中央に札が出る → 一人が引く → めくる → それぞれの役を提示
3. **対局** — 手番表示 / スコア / 器と液面 / メッセージ。押している間だけ注がれる。
   手番が移ると中央で告げ、告げ終わるまでは注げない
4. **一番の決着** — こぼした側の負け。器の名前とともに表示
5. **試合の決着** — 3本先取した側の勝ち

## 見た目の方向

和風。夜の茶室に灯りひとつ。青磁の土瓶と器、畳の床。緊張感は「注がれていく液面」で出す。
文字は見出しが毛筆、本文が明朝。

## 対戦相手（NPC）

一人で打つときは、二の手を NPC に任せる。際は誰にも見えているので、違いは
**どこで手を止めるか**だけに出る。強さの順に並べてある。

| 相手 | 狙う嵩 | 手の震え | 迷う時間 | 性格 |
|---|---|---|---|---|
| 老僧 | 0.62 | ±0.05 | 1.20秒 | 慎重。浅く置いて渡すので、こちらに余地が残る |
| 旅芸人 | 0.78 | ±0.18 | 0.80秒 | 気まぐれ。震えが大きく、自分でこぼすこともある |
| 武士 | 0.90 | ±0.07 | 0.45秒 | 豪胆。縁ぎりぎりまで注いで渡してくる |

狙いのぶれは Presenter が乱数で渡す（Model に乱数を持ち込まないため）。
狙いをすでに越えているときは、渡すのに要る最低限だけ注いで手を引く。
