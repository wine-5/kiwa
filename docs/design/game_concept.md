# 際 -KIWA- 注ぎ勝負

## テーマの解釈

お題「かさ」を **嵩（かさ）** と読み替える。枡に注いだ液体の「嵩」を competitors が交互に増やしていく。

## 一行で言うと

交互に注ぎ、こぼした方が負け。

## ルール

- プレイヤーと相手（NPC）が交互に枡へ注ぐ
- 注ぐ量は「押している間だけ注がれる」。離すと止まる
- 1回の手番で**最低限は注がなければならない**（パスできない）
- 枡があふれた瞬間、**注いでいた側の負け**
- こぼれる限界の量は毎回わからない（ラウンドごとに変わる）
- 勝敗はラウンドごとに加算し、スコアとして表示する

## 駆け引きの核

「限界が見えない」ことが全て。少なく注げば安全だが、その分こぼれるまでの余地を相手に残す。
多く注げば相手を追い込めるが、自分がこぼすリスクを負う。**際（きわ）をどこまで攻めるか**の勝負。

## 対戦相手

| 相手 | 性格 |
|---|---|
| 老僧 | 慎重 |
| 武士 | 豪胆 |
| 旅芸人 | 気まぐれ |

性格の違いは「どこまで攻めるか」の判断に出る。

## 画面の流れ

1. **セットアップ** — 対戦相手を選ぶ → 対局開始
2. **対局** — スコア表示 / 手番表示 / 枡の絵 / メッセージ / 注ぐボタン
3. **決着** — 次の勝負へ、またはスコアをリセット

## 見た目の方向

和風。生成りと木の色を基調に、明朝体。落ち着いた画面で、緊張感は「注がれていく液面」で出す。

## まだ決まっていないこと

- こぼれる限界量の決め方（範囲・分布）
- 注ぐ速度、1手番の最低量
- NPC の思考の具体
- 何本先取で1試合とするか
