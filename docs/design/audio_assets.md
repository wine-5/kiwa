# 音の設計と、必要な BGM / SE 一覧

このゲームに要る音を全部書き出したもの。作る順の目安と、鳴らす場所・鳴らし方も添える。

---

## 1. ゲーム概要（音を作る人向け）

**際 -KIWA- 注ぎ勝負**

夜の茶室。畳の上に湯呑がひとつ。灯りは行灯ひとつだけで、そのまわりは闇に沈んでいる。
二人は向かい合って座り、青磁の土瓶から**ひとつの湯呑へ交互に茶を注ぐ**。

- **際（限界）は器の口そのもの**。縁から溢れた瞬間に負けが決まる
- **器は毎局変わる**（ぐい呑・そば猪口・湯呑・茶碗）。入る量が違うので、
  あと何回注げるかの見当は毎回つけ直しになる
- 自分の番では**必ずいくらか注がなければならない**（回避できない）
- **こぼした側がその一番を落とす**。3本先取で勝ち
- 対局の前に**花月の札**を引いて先攻後攻を決める

**気配**：静けさと我慢、そしてじわじわ上がる緊張。派手な演出でなく、最後の一滴で
心臓が鳴るゲーム。茶道の所作の張り詰めた感じで、パーティゲームの賑やかさは要らない。

---

## 2. 音の方針

1. **主役は注ぐ音**。ほかの音はすべてその邪魔をしない音量・帯域に抑える
2. **静寂を敵にしない**。無音の間こそ緊張なので、BGM は鳴り続けなくてよい
3. **嵩は耳でも分かるようにする**。水位が上がるほど注ぎ音の響きが高くなる（実物と同じ）。
   これが「そろそろ危ない」という合図になるので、**注ぎ音はピッチを変えられる素材**にする。
   器が毎局変わるぶん、耳で嵩を測れることの価値は大きい
4. 和楽器は**一音ずつ置く**（旋律を作り込まない）。尺八・琴・鈴・拍子木・鹿威しなど
5. 音量は、注ぎ音を基準にして BGM はその下、環境音はさらに下

## 3. BGM（6本）

ループ前提。`assets/sounds/bgm/` に置く。

| ファイル名 | 場面 | 長さ | 雰囲気 |
|---|---|---|---|
| `bgm_title.ogg` | タイトル画面 | 60〜90秒 ループ | 尺八の長い一息と、遠くの鹿威し。旋律はほとんど無くてよい |
| `bgm_draw.ogg` | 札を引く場面 | 20〜30秒 ループ | 低い持続音だけ。息を詰める感じ。役が決まったら止める |
| `bgm_duel_calm.ogg` | 対局中（嵩が浅いうち） | 60〜120秒 ループ | ほぼ環境音。低い弦の持続音に、ときどき琴の一音 |
| `bgm_duel_tense.ogg` | 対局中（際が近いとき） | 上と**同じ長さ・同じ拍** | 上に重ねる層。低い太鼓の脈、弦の軋み。単体では旋律を持たない |
| `bgm_result_round.ogg` | 一番の決着 | 8〜12秒 ループ無し | 短い締め。勝ち負けどちらでも使える中立な一音 |
| `bgm_result_match.ogg` | 対局の決着（リザルト） | 30〜60秒 ループ | 静かな余韻。掛軸が下りる場面に重ねる |

> `bgm_duel_calm` と `bgm_duel_tense` は**同時に鳴らして音量だけを行き来させる**ので、
> 必ず同じ長さ・同じ頭出しで作ること。曲を切り替えると緊張の変化が段になって不自然になる。

## 4. 環境音（2本）

BGM とは別に、ずっと薄く鳴らし続ける。`assets/sounds/ambience/`

| ファイル名 | 内容 | 備考 |
|---|---|---|
| `amb_tearoom.ogg` | 茶室の間。炭のはぜる音、遠い虫の音、衣擦れ | 60秒以上・継ぎ目の分からないループ |
| `amb_rain.ogg` | 軒の雨（任意） | 雨の日の見た目にするなら使う |

## 5. SE

`assets/sounds/se/`。とくに書いていないものは 0.2〜1.5秒。

### 5-1. 画面まわり

| ファイル名 | 鳴る瞬間 | 音の質 |
|---|---|---|
| `se_cursor.wav` | 選択項目を移す | 木を軽く打つ音。ごく短く |
| `se_decide.wav` | 決定 | 拍子木を一度 |
| `se_cancel.wav` | 戻る | 低く短い木の音 |
| `se_scene_change.wav` | 場面の切り替わり | 襖が閉まる、または墨が飛ぶ音 |

### 5-2. 札（先攻後攻決め）

| ファイル名 | 鳴る瞬間 | 音の質 |
|---|---|---|
| `se_card_appear.wav` | 札が現れる | 和紙が擦れて止まる音 |
| `se_card_draw.wav` | 札を引く | 紙を引き抜く擦過音 |
| `se_card_flip.wav` | 札を返す | 紙が翻る軽い音。返り切る瞬間に合わせる |
| `se_role_decided.wav` | 先攻後攻が確定する | 鈴を一度。ここが一番の見せ場なので少し華やかに |

### 5-3. 注ぐ（このゲームの本体）

| ファイル名 | 鳴る瞬間 | 音の質 |
|---|---|---|
| `se_pot_lift.wav` | 土瓶を持ち上げる | 陶器が畳から離れる擦れ |
| `se_pot_tilt.wav` | 土瓶を傾け始める | 中の茶が寄る、ごく小さな揺れ |
| `se_pour_start.wav` | 注ぎ始め | 最初の一筋が水面を叩く音 |
| `se_pour_loop.wav` | 注いでいる間ずっと | **切れ目なく回せるループ**。1〜2秒。水位でピッチを上げるので、もとは低めに録る |
| `se_pour_stop.wav` | 注ぎ終わり | 筋が切れ、最後の数滴が落ちる |
| `se_pot_place.wav` | 土瓶を置く | 陶器が畳に触れる。手番の終わりの区切りになる |

> `se_pour_loop.wav` は**再生速度で音程を変える**前提。嵩 0%→100% で 1.0 倍→1.25 倍あたりを
> 動かす。素材に残響が入っていると伸ばしたとき不自然になるので、**残響なしの素**で録ること。

### 5-4. 際（きわ）

| ファイル名 | 鳴る瞬間 | 音の質 |
|---|---|---|
| `se_surface_tremble.wav` | 水面が縁と同じ高さになったとき | 表面張力が震えるような、極小の高い音。1回だけ |
| `se_meniscus_warn.wav` | 嵩が九分に届いたとき | 弦を爪弾いた残響。**鳴らしすぎない**。一番につき一度 |
| `se_spill.wav` | こぼれた瞬間 | 決定的な音。茶が縁を越えて畳へ落ちる。ここだけは大きくてよい |
| `se_spill_soak.wav` | こぼれたあと | 畳が茶を吸っていく、尾を引く湿った音 |

### 5-5. 手番と決着

| ファイル名 | 鳴る瞬間 | 音の質 |
|---|---|---|
| `se_turn_change.wav` | 手番が移る | 拍子木を一度。短く鋭く |
| `se_round_win.wav` | 一番を取る | 鈴一つ、澄んだ音 |
| `se_round_lose.wav` | 一番を落とす | 低い鐘。余韻を長く |
| `se_seal_stamp.wav` | 勝の落款が押される | 印が紙を打つ重い一撃 |
| `se_scroll_open.wav` | 掛軸が下りる | 紙が伸びて軸が揺れる |
| `se_match_win.wav` | 対局に勝つ | 鈴と拍子木を重ねた締め |

## 6. 数

- BGM 6 ＋ 環境音 2 ＝ **8本**
- SE **21本**

## 7. 作る順

1. `se_pour_loop` / `se_pour_start` / `se_pour_stop` / `se_spill` … これだけで勝負が成立する
2. `se_turn_change` / `se_round_win` / `se_round_lose` … 区切りが分かるようになる
3. 札の4つ … 先攻後攻決めが締まる
4. `amb_tearoom` / `bgm_duel_calm` / `bgm_duel_tense` … 場が出来る
5. 残り

---

## 8. 形式と置き場

| 種類 | 形式 | 置き場 |
|---|---|---|
| BGM・環境音 | Ogg Vorbis（長いので圧縮する） | `assets/sounds/bgm/` `assets/sounds/ambience/` |
| SE | WAV 16bit 48kHz（鳴り出しを遅らせない） | `assets/sounds/se/` |

いずれもモノラルでよい（画面が狭く、音源も中央に一つなので、左右に振る必要がない）。
読み込みは `IResourceManager::loadSound` を通す。
